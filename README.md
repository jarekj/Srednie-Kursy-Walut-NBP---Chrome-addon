Chrome addon/extension/rozszerzenie

Dodatek do przeglądarki "Średnie Kursy Walut NBP" to proste narzędzie dla wszystkich, którzy szybką chcą sprawdzić średnie kursy walut publikowane przez Narodowy Bank Polski. Dodatek umożliwia szybki dostęp do historycznych i aktualnych notowań bez konieczności odwiedzania strony NBP. Kliknięcie w kurs kopiuje go do schowka.
